## About

**TapType** is a typing speed test application built for speed, acoustic immersion, and clean aesthetics. It features customizable mechanical switch sound profiles (Gateron Yellow Thock, Cherry MX Blue Clicky, Creamy Pop, Typewriter, Cyberpunk 8-Bit) with real-time WPM, accuracy, consistency, and detailed performance breakdown.

## ✨ Features

| Area | Features |
|------|----------|
| **Test Modes** | Time (15s–120s), Word Count (10–100), Quotes |
| **Mechanical Sound Engine** | 6 Switch Profiles via Web Audio API (Linear, Clicky, Thock, Creamy, Typewriter, Cyberpunk) |
| **Focus Mode** | Clean, minimalist interface without on-screen keyboard clutter |
| **Real-time Analytics** | WPM, Raw WPM, Accuracy %, Consistency, Character breakdown, and WPM graph |
| **Themes & Fonts** | Multiple colorway themes & custom typography options |

## 🛠 Tech Stack

- **TypeScript**: Type safety across components and state logic.
- **Next.js 16**: Modern React framework with App Router.
- **React 19**: Responsive interactive UI.
- **Tailwind CSS**: Utility-first styling.
- **Web Audio API**: Low-latency acoustic synthesis & audio filters.

## 🧰 Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run the development server:
   ```bash
   npm run dev
   ```

3. Open (http://localhost:3005) in your browser.
